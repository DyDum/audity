# CIS Benchmarks Management

Application web pour la gestion de serveurs (script personnalisés) et l'audit CIS Benchmarks 

## Features

- ✅ Authentification (local, Azure AD, LDAP)
- ✅ MFA support
- ✅ Gestion serveurs
- ✅ Scans CIS
- ✅ Exécution SSH
- ✅ Exécution de scripts personnalisés
